Absolute Bezüge ($)

Schweizer Schreibweise: Semikolon, Punkt als Dezimalzeichen, Hochkomma als Tausender

Das Dollarzeichen fixiert Spalte, Zeile oder beides, damit sich ein Bezug beim Kopieren der Formel nicht verschiebt.

Syntax

$Spalte$Zeile · zum Beispiel $F$1, F$1, $F1
F1 (relativ)
Wandert beim Kopieren mit: nach unten F2, F3 …, nach rechts G1, H1 …
$F$1 (absolut)
Bleibt immer F1. Für feste Werte wie MwSt-Satz, Total oder Wechselkurs.
F$1 / $F1 (gemischt)
Nur die Zeile bzw. nur die Spalte ist fixiert. Für Tabellen, die nach rechts und unten kopiert werden.
Taste F4
Schaltet beim Bearbeiten durch F1 → $F$1 → F$1 → $F1 (Mac: cmd + T).

Fehlercodes und Ursachen

#NVEntsteht nicht durch $ selbst, aber oft in SVERWEIS-Formeln, deren Matrix ohne $ beim Kopieren verrutscht ist.
#NAME?Statt $F$1 ein Name verwendet (z. B. =B2*MwSt), der im Namens-Manager nicht definiert ist.
#WERT!Der kopierte Bezug zeigt auf eine Textzelle (z. B. die Kopfzeile) statt auf eine Zahl. #DIV/0!: Bezug zeigt auf eine leere Zelle.

Englisch – Deutsch

absolute reference = absoluter Bezug relative reference = relativer Bezug mixed reference = gemischter Bezug #REF! = #BEZUG! Komma , = Semikolon ;

Formeln aus englischen Foren übersetzen: Funktionsnamen ersetzen, Komma durch Semikolon ersetzen; der Dezimalpunkt bleibt.
