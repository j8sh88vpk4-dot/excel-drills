## Karussell-Konzepte

Format: 1080×1080 (Instagram) bzw. als PDF für LinkedIn-Dokument-Posts. Basis-Layout: `visuals/square.html` (weisser Grund, grüner Balken, Zellraster). 6–8 Slides, Slide 1 = Hook, letzter Slide = CTA.

### IG-K1 «3 Fehler, die jeder in SVERWEIS macht» · Fr 6.11.
1. **3 Fehler, die jeder in SVERWEIS macht** · Untertitel: «Und keiner gibt eine Fehlermeldung.»
2. **Fehler 1: FALSCH vergessen** · `=SVERWEIS(D2;A2:B6;2)` → sucht ungefähr, liefert falschen Preis
3. **So richtig:** `=SVERWEIS(D2;A2:B6;2;FALSCH)`
4. **Fehler 2: Matrix nicht fixiert** · Beim Runterziehen verschiebt sich A2:B6 → `$A$2:$B$6` (F4)
5. **Fehler 3: Spaltenindex falsch gezählt** · Matrix C:F → C = 1, D = 2
6. **Bonus: Suchspalte muss links sein** · Sonst XVERWEIS oder INDEX/VERGLEICH
7. **Lesen ≠ können.** Übe SVERWEIS gratis mit Sofort-Prüfung · Link in Bio · Excel-Drills

### IG-K2 «Excel auf Deutsch: Die 8 wichtigsten Übersetzungen» · Fr 13.11.
1. **SUM heisst bei dir SUMME?** · «Die 8 Übersetzungen, die du brauchst»
2. SUM → **SUMME** · AVERAGE → **MITTELWERT**
3. IF → **WENN** · IFERROR → **WENNFEHLER**
4. VLOOKUP → **SVERWEIS** · XLOOKUP → **XVERWEIS**
5. SUMIF → **SUMMEWENN** · COUNTIF → **ZÄHLENWENN**
6. **Und das Komma?** Wird zum Semikolon: `=WENN(A2>100;"hoch";"tief")`
7. **Speichern für später** · Excel-Übungen auf Deutsch: Link in Bio
